# Transient FinderChart v0.2.0

This prerelease adds an experimental native macOS 14+ SwiftUI interface alongside the Qt application and local web interface. The native interface calls the Python pipeline through a subprocess bridge; install the Python dependencies and launch it from source as described in the [native interface README](../../findingchart_macapp/README.md). No standalone macOS binary is provided.

## Changes since v0.1

- Add native controls for survey images, catalogs, slit and blind-offset overlays, inset charts, contrast, and visual fake-source injection.
- Improve catalog selection, distance cuts, PSF controls, inset rendering, and web export templates.
- Apply ESO/VLT and Gemini OT blind-offset conventions.
- Display and edit observation times in UTC in both desktop interfaces. Require an explicit timezone in the native bridge and reject parallactic PA calculations when the target is at or below the geometric horizon.
- Update the historical `La Palma` preset to the [Nordic Optical Telescope's published GPS position](https://www.not.iac.es/telescope/tti/technical-details.html).

## Validation

- `python3 -m pytest -q`
- `.venv/bin/python -m unittest discover -s tests -p test_observation_qt.py`
- `swift build -c release --disable-sandbox` in `findingchart_macapp/`

The local web server is for development use on `127.0.0.1`. The native bridge's pickle cache is trusted local state, not a format for untrusted input. Survey and catalog downloads require network access and were not part of the offline validation.
